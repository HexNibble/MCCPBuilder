# 第一阶段实现计划

1. **可运行骨架**：建立 WPF、Models、Core、Packaging、Tests 分层；支持新建、保存和打开项目。
2. **可验证输入**：完善包含/排除规则、文件树/清单、隐私扫描、Java 检测和完整生成前检查。
3. **安全构建流水线**：在独立临时目录复制 Payload，生成 LauncherConfig、Inno 脚本与完整日志，成功后原子发布。
4. **稳定启动入口**：实现 Launcher EXE、安全参数列表、强制 Java、登录提供方接口及脱敏启动日志。
5. **安装器验收**：调用官方 Inno Setup 6，验证安装位置、快捷方式、卸载注册项、升级、卸载和 SHA-256。
6. **系统测试**：在 Windows 10/11 x64 与不同 DPI、中文/空格/长路径、低权限和占用文件场景验收。

每一步作为可独立编译和测试的小模块推进；第一阶段功能验收前不投入正式安装程序视觉美化。
